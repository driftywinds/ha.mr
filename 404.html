ha.mr

(read: "hammer")

Consider removing parameters...
Some links include data that isn't necessary for the link to function, such as tracking information or page state. This data comes in the form of query parameters, marked by "?" and "&" characters.

Removing these segments can sometimes significantly shorten the link without breaking it. For example, an Amazon product link contains a lot of tracking information. Everything past the "?" symbol can be safely removed, making the link much shorter.

Enter a link above to compress
 




API

The same compression is available as a public API on this domain — no key or signup needed. Use it from the command line or in scripts.

Compress a link

curl -G https://ha.mr/api/compress --data-urlencode "url=https://example.com/some/long/path"
# → https://ha.mr#<payload>

JSON output

curl -G https://ha.mr/api/compress --data-urlencode "url=https://example.com" \
  -H "Accept: application/json"
{ "input": "https://example.com", "output": "https://ha.mr#~Uk6", "alphabet": "ascii", "domain": "ha.mr" }

POST works too (form or JSON body) for links with awkward characters. Errors return HTTP 400 with a plain-text (or JSON) message. Decompression isn't part of the API: opening a compressed link in any browser redirects to the original.
